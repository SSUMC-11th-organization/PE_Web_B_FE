# Week9 직접 확인·Notion 기록

## 실행과 계정

이 폴더에서 `pnpm dev --hostname 127.0.0.1 --port 3009`를 실행하고 http://127.0.0.1:3009 를 연다. 기존 Week8 공식 실습 서버 계정으로 로그인하면 되며 다시 가입할 필요 없다. 포트가 바뀌면 브라우저 저장소가 분리되므로 처음에는 다시 로그인한다. 3010은 로컬 가상 API 검증용이다.

## 직접 확인

1. 홈에서 목록·페이지 이동, 검색어 입력 후 검색 결과와 URL 확인. 검색 결과에서 새로고침·뒤로 가기를 해 본다.
2. 영화 카드로 상세 이동, 주소 직접 입력과 새로고침. 영화 제목·설명·포스터와 탭 제목을 확인한다.
3. 기존 계정으로 로그인하고 내 정보·닉네임 수정·새로고침 후 로그인 유지를 확인한다.
4. 즐겨찾기 추가 → 내 정보 목록 → 해제, 평점 등록 → 수정 → 새로고침 → 삭제를 확인한다.
5. 로그아웃 후 `/profile/edit`에 직접 접속하면 로그인 화면으로 이동하는지 확인한다. 없는 URL은 404 안내를 보여야 한다.

비밀번호·토큰을 캡처하거나 채팅에 보내지 않는다. 오류가 있으면 화면 문구와 해당 요청의 URL·상태 코드만 전달한다.

## Notion 필수 미션 토글 구성

### 구현 내용

> 기존 UMCine 기능을 유지하면서 Next.js App Router로 옮겼다. 폴더별 page와 layout으로 경로를 구성하고, TanStack Router 전용 API를 Next.js 링크·이동·URL 조회 API로 바꿨다. 서버 페이지와 상호작용 컴포넌트를 분리하고 로그인 토큰을 mount 이후 복원했다. 공개 영화 상세는 서버에서 조회하고 회원 데이터는 기존 Query 흐름을 유지했다.

### 핵심 코드

PR의 Files changed 또는 GitHub Week9 파일에서 다음 부분의 줄 번호를 선택해 고정 링크로 붙인다.

- `src/app/layout.tsx`, `src/app/providers.tsx`: 공통 레이아웃과 서버·클라이언트 경계.
- `src/app/(authenticated)/layout.tsx`, `src/components/layout/authenticated-layout.tsx`: 로그인 전용 경로 묶기.
- `src/stores/auth-store.ts`: 브라우저에서 토큰 복원 후 화면 표시.
- `src/app/movies/[movieId]/page.tsx`: 동적 경로와 서버 영화 조회.
- `src/screens/movies/search-page.tsx`: Next.js URL 조회·이동으로 검색 유지.

### 최종 확인 자료

- 홈 → 검색 → 상세 이동과 새로고침을 보여 주는 짧은 영상.
- 로그인 후 닉네임 수정·즐겨찾기·평점 동작을 보여 주는 영상 또는 결과 캡처.
- `pnpm build` 결과의 경로 표와 Next.js의 `○` / `◐` 표시 캡처.

코드 구조는 GitHub 링크로 보여 주고 사진은 실제 화면 동작 위주로 남긴다. 로컬 가상 검증과 본인 실제 서버 검증은 구분해 기록한다. 확인한 항목만 완료로 적고 마지막에 PR 링크를 첨부한다. 핵심 키워드·학습 후기·스터디 사진을 채운 뒤 Notion 공유 링크를 UMC에 제출한다.
